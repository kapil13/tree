## Plant — register belt segments and campus blocks as evidence

**Plant** means registration discipline along the industrial perimeter or campus, not only digging holes on event day.

1. Map the green-belt polygon, strip, or campus block against the EC condition / layout drawing before or on planting day.  
2. Capture GPS, species, photos, density notes, and programme tag (EC green belt, CSR campus, township, or contractor package).  
3. Assign a digital ID / passport so resurveys attach to the same physical unit or belt segment.  
4. Link contractor, nursery, and work-order documents to the same project / EC condition code.

Offline Android field apps matter on live refinery belts and active construction campuses; web dashboards matter for EHS, CSR, and compliance managers. Without clean Plant data, Track and Report become fiction when inspectors sample.

## Track — survival, stress, and re-planting on an industrial cadence

**Track** is the difference between a planting certificate and a living EC / CSR programme.

| Interval | Typical purpose |
|---|---|
| 0–30 days | Fix mis-tags; freeze baseline belt / campus registry |
| 3 months | First mortality signal; contractor warranty window |
| 6 months | Summer / monsoon stress check on perimeter belts |
| 12 months | Annual EC compliance / CSR / ESG reporting anchor |

Field crews record alive / stressed / dead / replaced — with a photo when status changes. Managers roll survival % by belt segment, contractor, site, or EC condition code. Optional satellite NDVI + SAR layers help prioritise long perimeters; they **guide** visits and do not replace ground truth for audit or EC packs.

Same survival loop as [mine green belt plantation monitoring](/resources/mine-green-belt-plantation-monitoring-india). Write resurvey ownership into contractor MoUs so the entity retains controlled records.

## Report — exports that survive EC sampling and BRSR adjacency

**Report** means a repeatable PDF / XLSX pack your EC compliance file, SPCB query response, CSR committee, or assurance team recognises:

- Tree / segment IDs, GPS, species, planting date, EC condition or CSR programme code  
- Survival snapshot for the reporting window  
- Methodology notes (GPS accuracy, mortality definitions, replacements)  
- Limitations (segments not yet resurveyed; modeled CO₂e labeled as estimate only)

Map the same fields to [BRSR Principle 6 plantation evidence](/resources/brsr-plantation-evidence-principle-6-india) when greening sits inside Principle 6 working papers; keep EC packs clearly tagged. See [BRSR / ESG](/solutions/brsr-esg). Do **not** treat modeled CO₂e or Green Credit narratives as substitutes for geo-tagged survival facts.
