Three modes, not six tabs

Each mode is a full-screen intent — user picks what they're doing today.

🌱

Plant mode

Corridor ribbon + gaps + camera-first inspector. Default for field supervisors.

Replaces: Trees tab + Register flow

🔍

Verify mode

Heat map of issues, geotag queue, photo gaps. Fix, don't browse.

Replaces: Compliance tab + survival alerts

📊

Report mode

Executive summary, export, credits ledger — for officers and auditors.

Replaces: Credits + settings + share panels

Mobile · Field mode (sunlight-ready)

Why this beats tabs (design principles)

Spatial, not categorical

Navigation follows chainage — how planters think.

Gaps invite action

Empty slots pulse. Registering feels like filling the corridor.

Context morphs

One inspector panel — tree, gap, or issue — no tab hunting.

Progress you feel

Ring + heat strip make 847/N tangible, not a table row.
