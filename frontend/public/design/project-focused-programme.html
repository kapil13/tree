Design rules for implementation

  1. One primary action per screen — “Register tree” or “Register here”.
  2. Max 4 zones on project page: header → progress → map+sidebar → tree list.
  3. Secondary pages for compliance, team, settings — linked, not embedded.
  4. Colour sparingly — forest green for actions; amber only for attention items.
  5. Register flow is separate — step list, not an 8-step wizard on first glance.
  6. Whitespace — if it feels crowded, remove a widget; don't shrink text.
