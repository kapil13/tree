Design notes

Palette matches current Flutter theme (forest green, soft surface, Live/Estimate honesty chips). Typography: Fraunces for titles, DM Sans for UI.

  • Login — shared; role comes from backend after sign-in
  • Field — Add tree dominant; Map + Alerts in tab bar
  • Map — polygon + linear tools; save to work areas
  • Supervisor — crew + priority monitoring
  • Exec — portfolio KPIs, projects, read-heavy
